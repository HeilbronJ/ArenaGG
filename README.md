# ArenaGG
Arena GG es una plataforma web que permite a los organizadores crear y gestionar torneos de videojuegos, 
facilitando la inscripción de participantes, la programación de partidas y el seguimiento de los resultados.

## Cómo ejecutar el proyecto
1. Clonar el repositorio con git clone y la URL del repo.
2. Abrir la carpeta en VS Code.
3. Abrir index.html en el navegador.
   
## Flujo de trabajo
- Una rama por historia (feature/, fix/ o docs/).
- Nadie sube directo a main: todo entra por pull request con una aprobación.
- Los mensajes de commit van en presente simple y explican claramente qué se hizo.

## ¿Cómo se prueba un Pull Request?
1. El compañero sube sus cambios: <br>
Guarda los cambios en un commit y los envía a GitHub con git push.

2. Crea un Pull Request (PR): <br>
En GitHub, el compañero solicita integrar sus cambios a la rama de destino, por ejemplo, develop.

3. Revisa el código: <br>
Comprueba que los cambios correspondan a la historia de usuario asignada, que no afecten otras funcionalidades y que sigan la estructura del proyecto.

4. Prueba los cambios: <br>
Ejecuta la aplicación y verifica que la funcionalidad opere correctamente. Si es posible, comprueba también que no se hayan generado errores en otras partes del sistema.

5. Aprueba el Pull Request: <br>
En GitHub, entra al Pull Request, selecciona Review changes, marca Approve y envía la revisión. Necesitas los permisos correspondientes.

6. Integra los cambios: <br>
Si todo está correcto y se cumplen las reglas del repositorio, se puede usar Merge pull request para integrar los cambios a la rama correspondiente.
